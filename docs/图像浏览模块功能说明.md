# 图像浏览模块功能说明

## 1. 文档目的

本文定义 WT32 图像浏览模块的产品功能、模式划分、图像工具、触屏交互和验收边界。

本文只描述用户可见的能力和行为，不指定图像渲染框架、图像处理库、硬件加速方式、数据缓存方式或其他研发实现方案。研发可自行选型，但最终行为必须满足本文要求。

WT32 是用于产品与界面验证的 CT 控制台原型，不作为临床诊断软件。图像、测量值和显示结果均用于浏览与功能验证，不应表达诊断结论。

## 2. 范围

### 2.1 本文包含

- 图像序列选择与加载状态。
- 2D、3D 模式的定义和切换规则。
- MPR、投影和体绘制等 3D 显示类型。
- 各类图像工具及其适用模式。
- 平板触屏设备上的工具选择、手势、模式切换和复位规则。
- 多视口联动、状态保留、异常降级和验收要求。
- 4D 序列在图像浏览模块中的扩展规则。

### 2.2 本文不包含

- 图像渲染、重采样、体绘制或投影算法的技术选型。
- 数据协议、接口、缓存、线程、GPU 或 CPU 实现细节。
- 扫描和离线重建参数的编辑逻辑。
- 诊断报告、PACS 工作流或临床结论。
- 真实设备控制和临床性能承诺。

## 3. 基本概念

| 名称 | 产品定义 |
| --- | --- |
| 序列 | 一组可连续浏览并具有共同图像属性的数据。 |
| 活动视口 | 当前接收工具操作的视口，必须用高亮边框或同等明显方式标识。 |
| 2D 模式 | 按原始序列逐层浏览图像的模式。 |
| 3D 模式 | 基于具备空间关系的序列进行多平面、投影或体绘制浏览的模式。 |
| MPR | 显示轴状面、冠状面、矢状面以及需要时的任意斜切面。 |
| 投影 | 对一定厚度范围进行 MIP、MinIP 或 Avg 显示。 |
| 体绘制 | 以三维模型方式显示体数据，可改变观察方向和显示预设。 |
| 图像旋转 | 仅旋转当前二维画面的显示方向，不改变采样切面。 |
| 切面旋转 | 改变 MPR 切面的空间方向，会影响关联视口中的参考线和重建结果。 |
| 三维旋转 | 改变投影或体绘制视口的三维观察方向，不改变 MPR 切面定义。 |

“图像旋转”“切面旋转”“三维旋转”必须作为三个独立工具命名和呈现，不得统一显示为含义不明的“旋转”。

## 4. 页面组成

图像浏览页面至少包括以下区域：

1. 序列列表：显示当前检查下可浏览的序列，并明确当前选中项。
2. 模式区：提供固定可见的“2D / 3D”切换控件。
3. 参数区：显示与当前模式和活动视口相关的显示参数。
4. 图像区：显示单视口或多视口布局，并明确活动视口。
5. 工具栏：只提供当前模式可用的工具，并持续显示当前激活工具。
6. 状态信息：显示加载、处理中、无数据、失败和不支持原因。

## 5. 2D 与 3D 模式

### 5.1 2D 模式

2D 模式用于查看单幅图像或连续层面序列，必须支持：

- 显示当前序列名称、当前层号和总层数。
- 通过层面浏览工具、上一层、下一层和连续播放浏览序列。
- 调节窗宽/窗位、选择窗模板和反色。
- 平移、缩放、适合窗口和图像旋转。
- 长度测量、文字标注及删除标注。
- 定位像等不具备体数据条件的序列仅进入 2D 模式。

### 5.2 3D 模式

3D 模式是包含多种显示类型的工作区，不等同于单独的体绘制画面。

#### 5.2.1 MPR

- 默认提供轴状面、冠状面和矢状面。
- 三个正交视口通过定位点和参考线联动。
- 移动定位点时，其他视口更新到同一空间位置。
- 切面旋转时，关联参考线和受影响的重建视图同步更新。
- 活动 MPR 视口可逐层浏览，也可在允许时进行厚层显示。

#### 5.2.2 投影

- 提供 MIP、MinIP 和 Avg 三种投影方式。
- 显示并允许调整投影厚度；数值单位应明确。
- 投影视口可与当前 MPR 位置或切面联动。
- 当投影视口采用三维观察方式时，可使用“三维旋转”；不能用“图像旋转”代替。

#### 5.2.3 体绘制

- 提供体绘制显示预设。
- 支持三维旋转、平移、缩放、适合窗口和视角复位。
- 体绘制中的显示预设与 2D 窗模板是不同概念，界面不得混用名称。

#### 5.2.4 布局

3D 模式至少提供：

- 三个 MPR 视口布局。
- 三个 MPR 视口加一个投影或体绘制视口的四窗布局。
- 单个活动视口放大与恢复布局。
- MPR 主视图和三维主视图布局。

切换布局不得改变选中序列、删除标注或修改图像显示参数。

### 5.3 模式可用条件

- 序列具备完整且一致的空间关系时，才允许进入 3D 模式。
- 定位像、单幅图像、层数不足或空间信息不足时，3D 按钮保持不可用，并显示具体原因。
- 3D 加载失败时保留 2D 浏览能力，不得让整个页面不可用。
- 元数据缺失时显示“未提供”或明确的不可用原因，不得猜测补值。

### 5.4 图像显示参数与离线重建的边界

以下项目属于图像浏览的显示参数，只改变当前浏览画面，不修改原始数据，也不生成新的重建序列：

- 窗宽/窗位和窗模板。
- 窗值曲线。
- 插值方式。
- 反色。
- 平滑和锐化显示强度。
- 投影方式、投影厚度。
- 体绘制预设和采样质量。

窗值曲线、插值、平滑和锐化只保留在图像浏览设置中，不在离线重建参数区显示。用户在图像浏览中调整这些项目时，不得将结果写回离线重建任务参数。

## 6. 平板触屏交互

### 6.1 触屏设计基线

- 所有主要操作必须能仅通过触屏完成，鼠标悬停、右键、滚轮和键盘快捷键不得成为必需条件。
- 主要触控目标建议不小于 44 × 44 显示像素，相邻目标之间保留足够间距。
- 图标必须配有文字名称，或在展开工具组后显示文字；不能只依赖用户猜测图标含义。
- 当前模式、当前活动视口、当前工具和当前显示类型必须一直可见。
- 核心操作最多两层触达；常用工具不放入需要长按才能发现的入口。
- 长按说明和双击快捷操作只能作为辅助，不能替代可见按钮。

### 6.2 2D / 3D 切换

- 使用固定可见、尺寸足够的“2D / 3D”分段按钮，不使用滑动手势切换模式。
- 点击已选中的模式不触发复位，也不重复加载。
- 首次进入普通序列时默认 2D；4D 等明确要求多平面观察的入口可默认 3D。
- 每个模式分别记忆上次使用的活动视口、布局、观察位置和工具；切回时恢复该模式的上次状态。
- 2D 与 3D 之间切换时，保留当前序列、窗宽/窗位、反色状态和已有标注。
- 当前工具在目标模式不可用时，自动切换为该模式的安全默认工具，并以短提示说明。
- 建议首次进入 2D 时默认“窗宽/窗位”，首次进入 3D 时默认“平移”。

### 6.3 3D 显示类型切换

- MPR、MIP、MinIP、Avg 和体绘制使用可点击按钮或触屏弹层选择，不依赖悬停菜单。
- 当前显示类型必须以文字和选中态同时表示。
- 切换显示类型时保留当前空间位置和可复用的观察状态。
- 显示类型不支持当前工具时，按模式切换规则自动回退到安全默认工具。

### 6.4 活动视口与工具选择

- 触碰某个视口后，该视口立即成为活动视口，并显示明显选中边框。
- 点击工具按钮后，工具保持激活，直到选择其他互斥工具或切换到不支持该工具的模式。
- 同一时刻只能有一个“单指拖动主工具”激活，避免平移、窗宽/窗位、旋转和测量同时响应。
- 工具按钮必须有未选、选中、按下和不可用状态；不可用时可点击查看原因，但不执行操作。
- 工具组弹层采用大尺寸列表或底部弹层，点击空白处或完成操作后关闭。

### 6.5 触屏手势

| 手势 | 行为 |
| --- | --- |
| 单击视口 | 激活视口；若当前工具需要点选对象，则同时执行该工具的点选行为。 |
| 单指拖动 | 执行当前激活的主工具，例如窗宽/窗位、平移、层面浏览、旋转或测量。 |
| 双指捏合 | 缩放当前视口，不改变当前主工具。 |
| 双指拖动 | 平移当前视口；与单指主工具互不冲突。 |
| 双击视口 | 可作为放大当前视口/恢复布局的快捷操作，但页面仍须提供可见按钮。 |
| 长按工具 | 可显示工具说明，但不得作为唯一入口。 |

层面浏览不使用无条件的左右滑动，因为该手势容易与平移、测量和模式切换冲突。用户选择“层面浏览”后，单指拖动才用于换层；同时保留上一层、下一层的可见按钮。

## 8. 复位规则

### 8.1 触屏入口

“适合窗口”保留为独立按钮，因为它是高频、低风险操作。点击“复位”按钮后打开大尺寸触屏弹层，按当前模式显示可用选项，不使用小型下拉箭头或依赖长按。

### 8.2 复位选项

| 选项 | 适用模式 | 执行内容 | 不应改变 |
| --- | --- | --- | --- |
| 适合窗口 | 全部 | 调整当前视口的缩放和居中。 | 窗宽/窗位、旋转、切面、定位点、标注。 |
| 复位当前视图 | 全部 | 恢复当前视口的平移、缩放和画面显示旋转；投影或体绘制同时恢复当前观察方向。 | 选中序列、窗宽/窗位、MPR 切面、定位点、标注。 |
| 恢复显示参数 | 全部 | 恢复当前序列默认的窗宽/窗位、窗值曲线、插值、反色、平滑、锐化、投影厚度、体绘制预设或采样质量。 | 选中序列、当前层面、切面方向、标注。 |
| 复位三维切面 | 3D | 恢复轴状面、冠状面、矢状面的默认正交关系，将定位点恢复到数据中心或序列初始位置。 | 选中序列、标注；窗宽/窗位保持不变。 |
| 全部复位 | 全部 | 恢复当前序列在当前模式下的默认布局、视图、显示参数和空间位置。 | 选中序列和标注不得被删除。 |

### 8.3 防误触

- “适合窗口”和“复位当前视图”单击后直接执行，并显示短提示。
- “复位三维切面”和“全部复位”会明显改变多个视口，执行前必须二次确认。
- 确认弹层须写明将复位的内容，并提供尺寸相当的“取消”和“确认复位”按钮。
- 复位操作不得删除测量或文字标注；删除标注必须走独立操作。
- 弹层关闭后焦点和活动视口保持不变。

## 9. 工具栏显示规则

1. 工具栏首先根据 2D 或 3D 模式过滤，再根据活动视口的显示类型过滤。
2. 不适用的工具原则上不显示；若为帮助用户理解暂时不可用的状态，可置灰并提供原因。
3. MPR 活动视口显示“图像旋转”和“切面旋转”，两者必须使用不同图标和完整文字。
4. 投影或体绘制活动视口显示“三维旋转”，不显示“切面旋转”。
5. 2D 活动视口只显示“图像旋转”，不显示“切面旋转”或“三维旋转”。
6. 选择新视口后，若原工具仍适用则保持激活；不适用则切换到安全默认工具并提示。
7. 测量、标注和删除工具可放入“标注”工具组，但展开后必须显示具体工具名称。
8. 窗值曲线、插值、平滑和锐化归入“显示设置”，不放入离线重建参数区。

## 10. 状态保留与联动

- 每个序列分别保存 2D 和 3D 的临时浏览状态，不将显示调整写回扫描协议或重建模板。
- 同一 3D 工作区内，窗宽/窗位可按产品设置在 MPR 视口间联动；界面必须明确联动是否开启。
- 三平面定位和切面旋转属于空间联动工具，更新时所有受影响视口应在同一交互过程中给出反馈。
- 图像旋转只影响当前视口，不传播到其他 MPR 视口。
- 三维旋转只影响当前投影或体绘制视口，不改变 MPR 定位点和切面方向。
- 切换序列后恢复该序列最近一次浏览状态；首次进入则使用序列默认状态。
- 离开图像浏览页面前无需将临时视图状态保存为扫描或重建参数。

## 11. 4D 序列扩展

- 时相浏览和层面浏览是两个独立维度，界面必须分别显示当前时相与当前层面。
- 进行跨时相对比或播放时，各时相的窗宽/窗位应保持一致或明确启用联动，避免显示差异被误认为数据差异。
- “连续播放层面”和“播放时相”使用不同名称、不同按钮状态，不能共用一个含义不明的播放键。
- 切换时相时尽量保持相同空间位置、活动视口、缩放和工具。
- 4D 的 MPR、投影和体绘制工具仍遵循本文的模式适用矩阵。

## 12. 加载、异常和降级

- 加载序列时显示明确进度或处理中状态，并允许返回序列列表。
- 序列无图像时显示“暂无可浏览图像”，不得显示空白黑屏而无解释。
- 3D 条件不足时说明原因，例如“图像层数不足”或“空间信息未提供”。
- 某个 3D 显示类型失败时，保留可用的 MPR 或 2D 视图。
- 工具执行失败时保持原状态，并在活动视口附近给出短提示。
- 数值、方向或空间信息无法可靠获得时显示“未提供”，不得推测。

## 13. 本期验收要点

### 13.1 模式与布局

- 仅通过触屏即可切换 2D、3D 和 3D 显示类型。
- 不支持 3D 的序列无法误进入 3D，并能看到原因。
- 3D 多视口能够明确标识活动视口，布局切换不丢失标注和显示参数。

### 13.2 工具

- 工具栏随模式和活动视口正确变化。
- 图像旋转、切面旋转和三维旋转名称、图标、作用对象均可区分。
- MPR 定位和切面旋转能正确联动相关视口。
- 不适用工具不会对当前视口产生意外操作。
- 所有主要工具均有足够大的触控区域和明确选中态。
- 窗值曲线、插值、平滑和锐化只改变浏览显示，且不出现在离线重建参数区。

### 13.3 切换与复位

- 模式切换不依赖滑动、悬停、右键或键盘。
- 切回模式时可恢复该模式上次的视图和工具状态。
- “适合窗口”只调整缩放与居中。
- “复位当前视图”不会重置三维切面、窗宽/窗位或删除标注。
- “复位三维切面”和“全部复位”必须二次确认。
- 任何复位操作都不得删除标注、切换序列或修改原始数据。

### 13.4 异常

- 无数据、加载失败、元数据不足和 3D 不可用均有明确反馈。
- 3D 失败后仍可继续使用 2D 浏览。
- 缺失信息不以猜测值或无说明的零值代替。

## 14. 研发交付边界

研发需要根据本文实现一致的产品行为，并自行决定具体的图像渲染、计算、缓存和性能优化方案。验收以用户可见的模式、工具、联动、触屏操作、复位边界、异常反馈和性能体验为准，不以某一种内部实现方式为准。
