# 已批准产品基线

本目录保存业务负责人已经明确批准、可用于后续设计与验收的产品边界和目标行为。

## 使用规则

- 基线描述 WT32 原型应达到的产品行为，不表示真实设备控制、临床诊断、治疗建议、最终剂量计算或剂量批准能力。
- 涉及扫描、剂量、呼吸、造影剂和安全状态时，继续使用“模拟、预计、参考、需确认”等限定语。
- 实现若与基线冲突，应先记录差异并获得新的明确决策，不得用当前代码现状覆盖已批准目标。
- 架构实现细节在需要时另行写入 `docs/adr/`；测试证据和实施过程保留在 `docs/working/`。
