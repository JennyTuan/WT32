# 患者列表页 验收标准

> 路由：`/patients`
> 代码位置：[ui-review/src/screens/PatientListScreen.tsx](../../ui-review/src/screens/PatientListScreen.tsx)
> 最后走查：2026-06-05

## 1. 用途

影像技师/医生在这里：
- 查看待检查患者，选中后进入扫描流程
- 查看已完成检查患者，选中后查看影像
- 增加新患者、删除待检查患者、（未来）导入/导出

## 2. 整体布局

- 顶部：AppHeader（沿用全局组件）
  - 选中**单一**患者时，header 显示该患者姓名 + 患者ID
  - 选中 0 个或多个时，header 不显示患者信息
- 中部：单卡片包裹的工具栏 + 表格 + 分页
- 底部：固定操作栏（上一步 / 下一步）

## 3. Tab 切换

| Tab | 显示状态 | 默认排序 |
|---|---|---|
| 待检查 | "待进行" + "已终止" | 序号升序 |
| 已完成 | "已完成" | 检查时间降序 |

- 切 Tab 时：清空搜索框、重置排序、保留选中（？待对齐 §9.A）

## 4. 表格列

**待检查 Tab**：
| 列 | 内容 | 排序 |
|---|---|---|
| ☐ | 行选中 | 否 |
| 序号 | 从 1 开始的递增（来自前端 index） | 可排 |
| 患者ID | 后端 patient_id | 可排 |
| 姓名 | 后端 name，受"隐藏姓名"控制 | 可排 |
| 性别 | 男/女/其他（中英文按 i18n） | 可排 |
| 年龄 | 由生日计算 | 可排 |
| 状态 | 待进行 橙 / 已终止 红 胶囊 | 可排 |

**已完成 Tab**：多出"检查项目"、"检查时间"两列；状态列变成可点的影像图标按钮（点击进入 `/image-viewer`）。

## 5. 显示规则

### 5.1 状态胶囊配色

- 待进行：橙色边框/底色（#FFF3E0 / #FA8C16）
- 已完成：绿色（#E8F5E9 / #43A047）
- 已终止：红色（#FFEBEE / #D32F2F）

### 5.2 姓名脱敏（Eye 按钮）

- 默认显示明文
- 启用脱敏后：
  - 1 字 → `*`
  - 2 字 → `张*`
  - 3+ 字 → `张**三`（首字 + 中间星号 + 末字）
- header 里的患者姓名同步脱敏

### 5.3 检查时间格式

- ISO 时间戳显示为 `YYYY/MM/DD HH:mm`（24 小时制，按当前 locale）

### 5.4 空数据

- 未加载 / 列表为空：表格主体为空，不显示占位文字（？待对齐 §9.B）

### 5.5 加载失败

- API 失败时，页面顶部 88px 处显示红色 toast（红底红字），写明错误信息

## 6. 操作规则

### 6.1 工具栏按钮

| 按钮 | 启用条件 | 行为 |
|---|---|---|
| 刷新 ⟳ | 总是 | 重新拉取患者列表 |
| 隐藏姓名 👁 | 总是 | 切换姓名脱敏；按钮态联动颜色 |
| 导入 ⬇ | 总是 | **？待对齐 §9.C：onClick 缺失，可能未实现** |
| 搜索框 | 总是 | 实时过滤（输入即过滤，无 debounce） |
| + 新增 | 总是 | 弹出 AddPatientScreen 模态框；新增成功后自动刷新列表并关闭 |
| ⬆ 导出 | ≥1 行被选中 | **？待对齐 §9.D：无 onClick，未实现** |
| 🗑 删除 | 仅在「待检查」Tab + ≥1 行被选中 + 所选行**全部为"待进行"状态** | 直接从前端列表移除 |

### 6.2 搜索过滤范围

- 待检查 Tab：匹配 姓名 / 患者ID
- 已完成 Tab：匹配 姓名 / 患者ID / 检查项目
- 大小写不敏感，trim 后匹配

### 6.3 排序

- 点击列头切换该列升降序
- 数字列按数值比，字符串列按当前 locale collation

### 6.4 选中

- 点击行任意位置 = 点击复选框：切换选中态
- 选中行底色变浅蓝（#E3F2FD）
- 表头复选框：全选/取消当前过滤后可见行
- 若已选中的行因刷新/搜索消失，自动清空选中

### 6.5 底部操作

| 按钮 | 启用条件 | 行为 |
|---|---|---|
| ← 上一步 | 总是 | 若 `location.state.backRoute` 存在则跳到该路由，否则浏览器后退 |
| 下一步 → | **恰好选中 1 个**患者 | 保存选中患者到 session，跳转：<br/>• 待检查 Tab → `/protocol-select`<br/>• 已完成 + 普通扫描 → `/image-viewer`<br/>• 已完成 + 4D 扫描 → `/image-viewer` 带 4D state（**？待对齐 §9.E：当前 4D 用 mock 数据**） |

按钮文案：待检查 Tab 显示"下一步"，已完成 Tab 显示"查看影像"。

## 7. 分页

- "每页 10 条" 文字 + 下拉框 UI，但实际**未实现**多页（？待对齐 §9.F）
- ⏮ ◀ 按钮始终禁用，▶ ⏭ 按钮可悬浮但无 onClick

## 8. 边界情况

- 单一患者选中时，header 显示该患者信息；选中多个或零个时清空
- 删除操作仅本地状态变更，**未调用后端 API** —— 刷新后患者会重新出现（？待对齐 §9.G，**判定为 BUG**）
- 长姓名/超长患者ID 是否截断？当前无样式控制（？待对齐 §9.H）
