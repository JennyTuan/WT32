# WT32 异地与真机环境问题反馈模板

## 1. 使用范围与边界

本模板用于收集无法由当前开发环境直接复现的问题，包括目标机、设备外壳内运行环境、异地联调环境和经授权的真机配套环境。

WT32 当前是用于产品与界面验证的 CT 控制台原型。本模板中的“真机”只描述测试发生的环境，不表示 WT32 已具备真实设备控制、临床诊断、治疗建议、最终剂量计算或剂量批准能力。涉及扫描参数、剂量、造影剂和安全状态的内容必须注明为**模拟值、参考值或估算值，并且需要确认**。

一条反馈只记录一个可独立定位的问题。若同一次测试中出现多个无直接因果关系的现象，应拆分反馈，并通过“关联反馈”互相引用。

## 2. 反馈标题

```text
[WT32][构建版本][环境][流程][阶段] 一句话描述实际现象
```

示例：

```text
[WT32][build-20260716.2][目标机][门控扫描][正式序列启动] 点击开始后返回流程校验错误
```

## 4. 首次接单检查表

接单人员先完成以下检查，再要求测试方补充材料：

1. 确认反馈只描述一个问题，标题能定位构建、环境、流程和阶段。
2. 检查时间、版本、路由、会话 ID、序列状态以及最短复现步骤是否齐全。
3. 将“观察事实”和“初步推测”分开，避免把推测当作结论。
4. 对照五条黄金流程，标记最早出现偏差的检查项。
5. 判断刷新或重试是否改变后端真实状态，避免只根据页面外观判断恢复成功。
6. 检查是否意外落入 mock、工程模式或静态影像数据源。
7. 先完成脱敏检查；需要新增共享权限或安全通道时，升级处理，不通过普通聊天补传敏感材料。
8. 若问题涉及扫描参数、剂量、造影剂或安全提示，只记录模拟 / 参考 / 估算呈现及确认流程，不作临床正确性批准。

## 5. 示例（虚构数据，仅示范填写颗粒度）

```text
反馈编号：WT32-ENV-20260716-01
环境：目标机；Windows 11；Chrome 版本待补；1024×768；触摸输入
版本：前端 1a2b3c4；后端 5d6e7f8
黄金流程：门控 / 正式序列启动
路由：/helical-execute?mode=gated_helical
测试患者标识：TEST-0042
scan_session_id：128

步骤：
1. 选择测试患者 TEST-0042 和门控螺旋协议。
2. 完成定位像模拟采集并进入门控确认页。
3. 点击开始正式序列。

预期：页面进入正式序列执行阶段，后端对应序列进入 running。
实际事实：请求返回 409；页面未进入采集计时；会话仍为 in_progress；正式序列仍为 pending。
初步推测：可能与定位范围确认状态有关，尚未验证。
发生频率：3 / 3。
恢复：刷新后仍可看到当前页面，但再次开始结果相同。
证据：脱敏网络摘要 env-01-network.txt；后端日志时间窗 14:22:10—14:23:10 CST。
```

该示例不代表问题已经在运行环境复现，也不构成需求、医学事实或安全结论。
