# 智能剂量调节（Auto-mA / DOM）PRD

> 版本：V1.0
> 模块：扫描确认页 - 智能剂量调节面板
> 出现位置：螺旋扫描确认页（HelicalScanConfirmScreen）、序列/断层扫描确认页（SequenceScanConfirmScreen）
> 适用人群：放射科技师（主），物理师 / 应用工程师（次）

---

## 1. 背景与目标

### 1.1 背景

CT 扫描的图像质量与受检者所受剂量始终是一对需要平衡的指标。目前 WT32 控制端在扫描确认环节中，技师只能基于经验手动设定固定 mA，存在两个问题：

1. 不同体型、不同部位的受检者使用同一档 mA，要么偏高造成不必要的剂量，要么偏低导致图像噪声超出预期。
2. 技师无法在扫描前直观看到本次扫描沿 Z 轴的剂量分布，也无法预估"调整 mA 范围"会带来的效果差异。

### 1.2 目标

在扫描确认页提供一个一键开启的「智能剂量调节」面板，让技师能够：

1. 在不离开扫描确认页的前提下，开启 / 关闭智能剂量调节。
2. 直观看到本次扫描在 Z 方向（以及螺旋时间轴上）的预估 mA 曲线。
3. 通过 **mA 上限 / mA 下限 / 噪声等级** 三个控制项快速调整剂量策略，曲线实时联动反馈。
4. 在曲线上拖动定位线，查看任意位置 / 任意时刻的预估 mA、Z 位置、机架角度等关键值。

最终让技师在执行扫描前就能对剂量分布做到「心中有数」，而不是事后看剂量日志才发现偏差。

## 2. 功能入口与展示形态

### 2.1 入口

扫描确认页左侧参数区第一行的 **「智能剂量调节」开关**。

- 默认状态：跟随当前协议中的 `auto_ma` 字段。协议里开启过的，进入扫描确认页后默认开启。
- 开关打开时：在图像区域下方展开智能剂量调节面板。
- 开关关闭时：面板收起，图像区域恢复满高度，扫描使用协议中的固定 mA。

### 2.2 适用扫描模式

| 扫描模式 | 是否支持 | 说明 |
|---|---|---|
| 螺旋扫描 | 支持 | 曲线沿时间轴展开，体现转一圈内的角度调制 |
| 序列 / 断层扫描 | 支持 | 曲线按床位分段展示，每段为一个床位采集 |
| 定位像 | 不支持 | 定位像本身就是低剂量预扫描，不开启该面板 |
| 4D 扫描 | 暂不支持 | 涉及多时相，第一版不开放，后续单独评估 |

### 2.3 面板布局（参考截图）

面板分为左右两部分（左宽右窄）：

- **左侧：mA 曲线图**
  - 顶部一行光标读数：`t`（时间）/ `Z`（轴向位置）/ `theta`（机架角度，仅螺旋）/ `mA`（当前光标位置的预估 mA，黄色高亮）
  - 主体为 mA(z) / mA(t) 折线，蓝色
  - 顶部、底部两条红色虚线分别表示 **mA 上限** 和 **mA 下限**
  - 黄色垂直线为当前定位线
  - 横轴按床位边界（19.2mm）打刻度

- **右侧：参数控制**
  - MA 上限 (MAX)：滑块 + 数值
  - MA 下限 (MIN)：滑块 + 数值
  - 噪声等级：滑块 + 数值（1-10，默认 5）

## 3. 功能详细需求

### 3.1 开关行为

- 开关切换时立即生效，无需"应用"按钮。
- 关闭时：保留之前的 mA 上限 / 下限 / 噪声等级配置，再次开启时恢复。
- 开关状态写回到本次扫描会话（scan session）的 `auto_ma` 字段，不回写到协议模板。

### 3.2 mA 上限 / mA 下限（具体数值后续确定）

| 项 | 要求 |
|---|---|
| 取值范围 | 整机硬限：20 mA - 800 mA |
| 上下限关系 | 上限 - 下限 ≥ 5 mA，越界时滑块自动夹取 |
| 默认值 | 取当前协议 mA 的 50%（下限）和 120%（上限），上限不超过 800 |
| 步长 | 1 mA |
| 实时反馈 | 滑块拖动时曲线图上的红色上下限虚线实时跟随；mA 曲线被夹取在新区间内重绘 |
| 写回 | 滑块停止操作 200ms 后写回 scan session 的 `ma_min` / `ma_max` |

### 3.3 噪声等级（具体数值后续确定）

| 项 | 要求 |
|---|---|
| 取值范围 | 1 - 10 |
| 步长 | 1 |
| 默认值 | 5 |
| 含义 | 数值越大 = 容许图像噪声越大 = 整体 mA 降低；反之 mA 提高 |
| 实时反馈 | 拖动时曲线整体上下浮动 |
| 写回 | scan session 的 `noise_level` 字段（如后端尚未提供，请新增） |

> 备注：噪声等级当前是产品语义层面的一档"图像质量目标"，具体到底层 mA 缩放系数、噪声指数 NI 的换算公式，由扫描控制 / 剂量引擎团队最终确认。控制端只负责把这个 1-10 的整数透传下去。

### 3.4 曲线交互

| 操作 | 效果 |
|---|---|
| 单击曲线 | 定位线移动到点击位置，顶部读数刷新 |
| 拖拽曲线 | 平移视图窗口（缩放后可见多床位时） |
| 滚轮 | 以鼠标位置为中心缩放视图窗口，最小为 1 个床位（19.2mm） |
| 双击 | 视图重置为全扫描范围 |

定位线位置应与图像区域中的扫描位置指示器（如有）同步联动。

### 3.5 光标读数

光标读数始终对应当前定位线所在位置：

| 字段 | 螺旋 | 序列 |
|---|---|---|
| t | 当前时刻（s） | 当前时刻（s，按床位顺序累加） |
| Z | 当前 Z 位置（mm） | 当前 Z 位置（mm） |
| theta | 机架角度（0-360°） | 不显示 |
| mA | 当前位置预估 mA（黄色高亮） | 同左，另显示 `bed N/M` |

### 3.6 曲线数据来源

mA 曲线优先使用基于定位像 HU 值反推的"物理曲线"（已经存在 `lib/doseModulation.ts`）。当定位像数据不可用时，回退为按"中间高、两端低"的钟形包络曲线 + 角度方向的正弦波动合成。该回退方案仅用于占位演示，不应被技师当作真实剂量参考。

> UI 层不计算最终曝光曲线，只负责展示"预估"。所有标签建议带"预估 / 参考"字样，避免被误读为承诺剂量。

## 4. 与其他模块的关系

### 4.1 与协议模板

- 协议模板中的 `auto_ma` / `ma_min` / `ma_max` 作为进入扫描确认页时的默认值。
- 在扫描确认页内的调整 **只影响本次扫描**，不回写模板。
- 后续可以考虑增加「另存为协议默认」按钮，本期不做。

### 4.2 与剂量预估（CTDIvol / DLP）

- 智能剂量调节面板的 mA 上下限 / 噪声等级变化，应触发扫描确认页右上角 CTDIvol / DLP 预估值的重算。
- 如果 CTDIvol / DLP 超过协议的通知阈值，沿用现有的剂量超限提示流程。

### 4.3 与剂量日志

- 本次扫描是否启用智能剂量调节、最终的 mA 上下限、噪声等级、预估 CTDIvol / DLP，均应在剂量日志（`/service/dose/logs`）中保留。
- 日志层面字段补齐若涉及后端 schema 改动，请同步评估。

### 4.4 与执行扫描按钮

- 智能剂量调节开启时，「执行扫描」按钮点击后，下发的 scan session 参数中需要带上 `auto_ma=true` 及对应的 `ma_min` / `ma_max` / `noise_level`。
- 智能剂量调节关闭时，下发固定 mA（来自协议 / 用户手动设定）。

## 5. 异常与边界场景

| 场景 | 处理方式 |
|---|---|
| 定位像未完成 / 无 HU 数据 | 面板可以开启，曲线使用回退合成曲线，光标读数照常显示 |
| 协议中 `ma_min` 或 `ma_max` 缺失 | 按 3.2 节默认值规则补齐，写回 scan session |
| 扫描长度 = 0 或异常 | 面板隐藏，开关置灰，提示"扫描范围未设置" |
| 用户把上下限拖到几乎重合 | 自动保持至少 5 mA 间距 |
| 拖动滑块过程中切换序列 / 离开页面 | 当前未提交的值丢弃，已生效的写回值保留 |
| 4D / 定位像模式 | 开关与面板均不出现 |

## 6. 文案与视觉

### 6.1 文案

| 位置 | 文案 |
|---|---|
| 开关 | 智能剂量调节 |
| 滑块 | MA 上限 (MAX) / MA 下限 (MIN) / 噪声等级 |
| 单位 | mA / mm / s / deg |
| 光标读数前缀 | t / Z / theta / mA |
| 回退曲线提示 | 当前为参考曲线，启用扫描后将以实际曝光为准 |

### 6.2 视觉

- 面板背景：深色（与扫描确认页底部参数栏一致）。
- 曲线主色：蓝色 #60A5FA（开启）/ 灰色 #475569（关闭）。
- 上下限虚线：红色 #F87171。
- 定位线 / 当前 mA 高亮：黄色 #FBBF24。
- 面板高度参考截图，不应挤压图像区域过多（建议 ≤ 200px）。

## 7. 验收标准

### 7.1 基础功能

- [ ] 螺旋扫描确认页可以打开 / 关闭智能剂量调节，面板展开 / 收起动画流畅。
- [ ] 序列扫描确认页可以打开 / 关闭智能剂量调节，曲线按床位分段。
- [ ] 三个滑块拖动时曲线实时联动，不卡顿。
- [ ] 滑块停止操作后值正确写回 scan session，刷新页面后仍然保留。

### 7.2 曲线交互

- [ ] 单击曲线可定位，光标读数刷新。
- [ ] 滚轮可缩放，缩放窗口能按床位边界对齐。
- [ ] 拖拽可平移视图。
- [ ] 双击可重置视图。

### 7.3 联动

- [ ] mA 上下限 / 噪声等级变化时，右上角 CTDIvol / DLP 预估值同步变化。
- [ ] 超过协议通知阈值时弹出剂量超限提示。
- [ ] 关闭智能剂量调节后，扫描参数恢复为协议中的固定 mA。

### 7.4 数据落库

- [ ] 本次扫描的 `auto_ma` / `ma_min` / `ma_max` / `noise_level` 正确写入 scan session。
- [ ] 剂量日志中能看到本次扫描是否启用智能剂量调节及最终参数。

### 7.5 异常

- [ ] 定位像未完成时面板可开启，使用回退曲线且有提示。
- [ ] 扫描长度异常时开关置灰。
- [ ] 4D / 定位像模式下面板不出现。

## 8. 不在本期范围

以下功能后续单独立项评估，本期不做：

1. 器官保护型角度调制（即真正意义上的 DOM）：选择保护器官、保护方向、强度等级等。
2. 4D 扫描下的智能剂量调节。
3. 基于患者年龄 / 性别 / 体型的自动推荐。
4. 定位像中自动识别保护区域。
5. 实际 mA(t) 曲线回传与回放。
6. 协议级别的「另存为默认」。
